这是一个基于Architectury的Minecraft现代装饰模组，具有强烈的中式风格。<br>
本页面不发布Release，需要游玩的可以前往https://www.mcmod.cn/class/14045.html （国内）或https://modrinth.com/mod/citymod （全球）下载<br>
由于受到“豹猫指示牌”的竞争，本模组开发方向已转向现代高模内饰，交通方面更新会大规模推迟与停更<br>
模组支持Neoforge/Forge/Fabric 1.20.1 1.21.1 26.1-26.2，1.19及以下将不受支持。 <br>
你可以自由把此模组加入整合包，只要你不使用这个整合包盈利。对于MCR制作的0.x版本同样适用。<br>
